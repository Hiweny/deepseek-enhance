# DeepSeek Chat 全功能增强

Tampermonkey 用户脚本，为 DeepSeek Chat 添加丰富的增强功能。

## 功能

### 基础增强
- **气泡分割** — AI 回复按 `---` 分隔线拆分为独立气泡，带弹出动画
- **全局背景** — 上传自定义背景图，支持模糊度和遮罩透明度调节
- **一键全屏** — 快速切换全屏模式，输入框自动撑起
- **防撤回** — 拦截 AI 消息撤回，显示本地缓存内容
- **Mermaid 渲染** — 内置 SVG 渲染引擎，支持流程图/时序图/饼图/甘特图/状态图/类图
- **主题系统** — 5 套主题 (默认/Dracula/咖啡/赛博朋克/全黑) + light/dark/auto 模式
- **气泡预设** — 3 种样式 (默认/iOS毛玻璃/水玻璃)
- **缩放系统** — 页面缩放 50%-200%，含预设按钮

### 消息导航
- **上下按钮** — 以对话轮次为单位快速跳转
- **自动隐藏** — 滚动时显示，停止后 2.5 秒自动隐藏
- **按钮分离** — 上下按钮间距加大，不易误触
- **高亮提示** — 跳转后高亮目标消息

### 时间注入 (全局)
- 在每条消息中隐式注入当前时间
- 让 AI 拥有准确的时间感知
- 可在设置面板中开关

### 隐私模式 (独立界面)
- **独立全屏界面** — 与 DeepSeek 原生界面完全隔离
- **本地长期对话维护** — 所有对话历史由本地存储，完整拼接到每次请求
- **独立人格系统提示词** — 可自定义 AI 人格和行为规则
- **智能上下文管理** —
  - 支持全量消息 (带智能截断，50k token 硬限制)
  - 可配置上下文条数 (滑动窗口)
  - 超限自动截断早期消息并提示
- **自动总结** — 上下文超过阈值时自动生成总结并新建对话
- **手动总结** — 随时手动生成总结并继续
- **多对话管理** — 对话编号 (PRIVACY-001, 002...)，可切换/归档
- **防撤回** — 被撤回的消息在本地缓存，标记后继续使用
- **越狱能力** — 系统提示词支持不受常规安全过滤限制的对话
- **API 会话管理** — 尝试创建新的 DeepSeek 会话并重命名
- **代码复制** — 代码块悬停显示复制按钮
- **Token 监控** — 实时显示上下文用量，进度条可视化

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击下方 Raw 文件链接，Tampermonkey 会自动识别并安装
3. 或在 Tampermonkey 中新建脚本，粘贴完整代码

> [Raw 文件 (v5.3)](deepseek_enhanced_v5.user.js)

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+Shift+B` | 打开/关闭设置面板 |
| `Ctrl+Shift+↑` | 上一轮对话 |
| `Ctrl+Shift+↓` | 下一轮对话 |

## 使用隐私模式

1. 先在普通模式下发送一条消息 (脚本需要捕获请求模板)
2. 打开设置面板 (Ctrl+Shift+B) → 高级功能 → 进入隐私模式
3. 在隐私模式界面中发送消息，所有对话由本地维护
4. 可在设置中配置系统提示词、上下文条数、自动总结等
