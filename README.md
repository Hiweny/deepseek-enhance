# DeepSeek Enhance

面向 [chat.deepseek.com](https://chat.deepseek.com/) 的油猴增强脚本：界面美化、IM 风格气泡、防撤回、提示词工程、长期记忆、思考自动折叠、上下文用量等。手机浏览器（Kiwi / Edge / Safari 油猴扩展）与桌面端均适配，明暗双色自适应。

## 安装

先安装 Tampermonkey（或兼容用户脚本管理器），再点击安装：

**[deepseek-enhance.user.js](https://raw.githubusercontent.com/Hiweny/deepseek-enhance/main/deepseek-enhance.user.js)**

更新检查 meta：[deepseek-enhance.meta.js](https://raw.githubusercontent.com/Hiweny/deepseek-enhance/main/deepseek-enhance.meta.js)

设置入口在输入框工具条上（「深度思考 / 联网搜索」旁边的齿轮），位置与官网原生按钮一致。

## 功能

### 外观
- **全局背景**：内置默认背景图，支持填图片 URL 或上传本地图片；亮度 / 模糊可调（旧版无效的“透明度”已替换为亮度）。
- **水玻璃气泡**：三种质感预设，AI 与用户气泡都带 IM 风格小尾巴，明暗自适应。
- **输入框磨砂玻璃**：悬浮毛玻璃，并修掉输入框下方的白色/黑色渐变条。
- **顶栏统一**：标题区与分享按钮合并为同一条磨砂栏（修复移动端分享按钮单独一块底色的问题）。
- **Markdown 美化**：标题、代码块、表格、引用、行内代码统一排版，避让官网原生 Mermaid 渲染。
- 隐藏 AI 消息底部操作栏（复制/刷新/赞/踩）与“内容由 AI 生成”标识（均可在设置里开关）。
- 移除移动端欢迎页的“下载应用”按钮。

### 对话
- **多条消息（反斜杠分条）**：独立开关。AI 回复**完成后**按单独一行的 `\` 切成多条气泡，随机间隔依次浮现，模拟真人连发；代码块与复制按钮完整保留；刷新/重进对话按内容幂等复原，不会重复切割或重播动画。开启时会在提示词中告知 AI 分条规则。
- **思考自动折叠**：独立开关，默认开启，自动收起“深度思考”过程；与其它同类自动折叠脚本共存，不互相反向展开。
- **消息导航**：保留右侧上下两个跳转按钮。
- **上下文用量**：只在设置面板内显示当前会话 token 用量与进度条，达到阈值提示开新对话（不在对话界面插 UI）。

### 提示词工程（全部透明、可编辑、绝不显示在用户气泡里）
- 所有注入内容只改写网络请求的 `prompt` 字段，并用标记包裹；历史接口回读时自动剥离，刷新、重新生成、换设备都不会让系统提示词出现在气泡中。设置面板「角色 / 高级」里可预览实际注入结果、编辑每段模板。
- **AI 助手模式（默认）**：系统提示词按会话隔离、独立开关；默认 Markdown 开启、分条关闭、时间关闭、智能防撤回。
- **Waifu 长期陪伴模式**：系统提示词跨会话持久；内置出厂范例（第一人称、身份不混淆）；带对话上下文窗口。
  - **长期记忆总结**：手动“立即总结”或超阈值自动触发。总结请求直接在**当前对话**输入框中由官网原生管线发送（不绕底层接口），AI 的第一人称总结回复自动存为长期记忆，并从本地上下文窗口剔除该轮，防止摘要堆叠膨胀；自动触发前会弹 toast 提示。

### 隐私 / 防撤回
- SSE 流到达前缓存真实内容，撤回信号（模板替换 / CONTENT_FILTER）到达时替换为本地缓存。
- **智能模式**：连续撤回连续回填；一旦 `fetch_page` 整体重载上下文，自动清掉服务端已承载的旧撤回，只回填最新缺失轮；并提示 AI 极简回应、自然转题，降低再次撤回概率。
- **全量模式**：每轮携带指定条数的完整本地历史。
- 历史按会话隔离，可在面板清除。

### 其他
- 时间注入开关、页面缩放、面板五页签（外观 / 对话 / 角色 / 隐私 / 其他），移动端底部弹层不溢出。

## 项目结构

```
src/
  header.user.js        油猴 metadata
  bootstrap.js          IIFE 外壳、GM/localStorage 桥、事件总线（注入版共用）
  core/                 config 存储、选择器表、工具函数、统一网络层
  styles/               全部样式（CSS-in-JS 模块）
  modules/              背景、气泡、思考折叠、防撤回、提示词、总结、导航、缩放、顶栏微调等
  settings/panel.js     设置面板
  main.js / footer.js   装载顺序与收尾
build.js                一键拼接：根目录 user.js / meta.js + dist/inject.js
dist/inject.js          无 GM 环境注入版（供 WebView 套壳使用）
docs/                   官网 DOM/协议实地调研档案与架构说明
```

## 构建

```bash
node build.js
```

产物：`deepseek-enhance.user.js`、`deepseek-enhance.meta.js`、`dist/inject.js`（三者内容同源，文件名不带版本号）。

## 自测

`harness/` 目录为 Playwright 真机自测脚本（驱动真实 DeepSeek 页面，PC 1440×900 / 移动 390×844、明暗双色），覆盖分割算法、请求注入与历史剥离、防撤回状态机、思考折叠、总结链路、面板与视觉走查。

## 说明

- 脚本依赖官网当前的 CSS 类名与接口结构，官网大版本更新后个别选择器可能需要更新，集中维护在 `src/core/selectors.js` 与 `docs/dom-research.md`。
- 默认背景图为外链，失效后可在设置中更换 URL 或上传本地图片。
