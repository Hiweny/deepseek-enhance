# DeepSeek Chat 全功能增强

Tampermonkey 用户脚本，为 DeepSeek Chat 添加丰富的增强功能。

## 功能

- **气泡分割** — AI 回复按 \`---\` 分隔线拆分为独立气泡，带弹出动画
- **全局背景** — 上传自定义背景图，支持模糊度和遮罩透明度调节
- **一键全屏** — 快速切换全屏模式，输入框自动撑起
- **防撤回** — 拦截 AI 消息撤回，显示本地缓存内容
- **Mermaid 渲染** — 内置 SVG 渲染引擎，支持流程图/时序图/饼图/甘特图/状态图/类图
- **主题系统** — 5 套主题 (默认/Dracula/咖啡/赛博朋克/全黑) + light/dark/auto 模式
- **气泡预设** — 3 种样式 (默认/iOS毛玻璃/水玻璃)
- **消息导航** — 右侧导航栏快速跳转消息，支持全部/用户/AI 筛选

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/) 浏览器扩展
2. 点击下方 Raw 文件链接，Tampermonkey 会自动识别并安装
3. 或在 Tampermonkey 中新建脚本，粘贴完整代码

> [Raw 文件](deepseek-all-in-one.user.js)

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| \`Ctrl+Shift+B\` | 打开/关闭设置面板 |
| \`Ctrl+Shift+↑\` | 上一条消息 |
| \`Ctrl+Shift+↓\` | 下一条消息 |
