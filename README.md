# DeepSeek 全功能增强脚本

一个功能丰富的 DeepSeek 网页端增强 Tampermonkey 脚本。

## 安装

点击下方链接安装（需要先安装 [Tampermonkey](https://www.tampermonkey.net/)）：

**安装链接：** https://raw.githubusercontent.com/Hiweny/deepseek-enhance/main/deepseek_enhanced_v5.user.js

## 功能列表

- **气泡分割** — 用户和AI消息气泡样式美化，支持多种预设（默认/毛玻璃/水玻璃）
- **全局背景** — 自定义背景图片，支持模糊和透明度调节
- **防撤回** — 拦截 DeepSeek 的消息撤回，将被撤回的内容保存在本地
- **隐私模式（智能）** — 检测到撤回时自动回填整轮对话（用户消息+AI回复）到上下文
- **隐私模式（全量）** — 将所有历史消息拼接注入到prompt中，可设置发送给AI的消息条数
- **会话隔离** — 隐私模式历史按会话ID隔离，切换对话不会混淆
- **时间注入** — 在每条消息中隐式注入当前时间
- **消息导航** — 右侧上下按钮快速定位消息（参照 My-Prompt 项目实现）
- **Mermaid 渲染** — 内置 SVG 渲染引擎
- **主题系统** — 5个主题 + light/dark/auto 模式
- **缩放系统** — 页面缩放控制

## 隐私模式说明

| 模式 | 行为 |
|------|------|
| 关闭 | 不注入任何历史，仅时间注入（如开启） |
| 智能模式 | 仅当检测到撤回消息时，回填整轮被撤回的对话（用户消息+AI回复） |
| 全量模式 | 每次请求拼接全部历史消息（可设置条数上限），不做总结直接隐式展示 |

## 消息导航

- 右侧中间位置有上下两个小按钮
- 按钮默认半透明，鼠标悬停时完全显示
- 点击上/下按钮在消息之间跳转，自动高亮目标消息
